# Qadam and the Algorithm Archipelago

Interactive 3D book for **AI Fundamentals (AIF1303)**, Qairu University, Weeks 1–10.
Team 11: Yuldashov Bilal, Tashmetov Shakhrukh.

Open the book: https://b21657934-wq.github.io/qadam-archipelago/

- 🌍 World: ten floating islands, one 3D lab per week (search, local search, games, MDP/RL, Bayes, HMM, decisions & ML, neural networks, LLMs).
- 📖 Book: full textbook chapters with diagrams, formulas explained symbol by symbol, worked exam problems, live Python labs and quizzes.

Single self-contained `index.html` (three.js bundled); works offline and on phones.
AI use is disclosed inside the book (Team, AI use & sources).
